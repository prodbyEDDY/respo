# Дизайн-система Respo (адаптация Family Style Reference)

Источник токенов: [FAMILY-STYLE-REFERENCE.md](FAMILY-STYLE-REFERENCE.md). Визуальный
референс раскладки: скриншот-концепт «Light Studio» (утверждён 2026-08-28, DESIGN-01).

## Что берём из Family

- **Палитра** целиком (cream/stone/ink + акценты: link-blue #0086fc, ember-orange #ff3e00, mint, honey, coral, plum).
- **Приём границ:** карточки и панели определяются 1px inset-хэйрлайном (#f2f0ed), не тенями. Максимум тени — `--shadow-sm`.
- **Радиусы:** карточки/панели 10px, бейджи 6px, пилюли 9999px.
- **Типографика:** Inter 400/500/600, шкала micro(12)/caption(15)/body(17)/subheading(19)/heading(23). Спейсинг база 4px.

## Что меняем (Respo — инструмент, не лендинг)

- **Без сторибука:** маскоты, конфетти, display-шрифт Family (68px) — не используем. UI-хром тихий и плотный.
- **Плотность:** тулбары компактнее «comfortable» лендинга: высота топ-бара ~48px, шапки девайсов ~36px.
- **Роли цветов в приложении:** link-blue #0086fc — активные состояния (активный вьюпорт, SYNC-чип, primary-кнопки — как на утверждённом скриншоте); ink #121212 — текст/иконки; ember-orange — только инлайн-ссылки и предупреждающие акценты; alert-red — ошибки загрузки/краши; mint — статус «connected/ok».

## Тёмная тема (выведена из светлой, тёплая)

| Роль | Light | Dark |
|---|---|---|
| canvas (фон окна) | #fbfaf9 | #151413 |
| surface (карточки/панели) | #ffffff | #1e1d1b |
| stone (inset-борды, вторичные поверхности) | #f2f0ed | #2a2927 |
| sand (вторичные кнопки) | #f6f4ef | #242322 |
| text-heading | #343433 | #f2f0ed |
| text-body | #474645 | #c9c7c4 |
| text-muted | #7e7e7d | #8a8886 |
| accent | #0086fc | #4da3ff (чуть светлее для контраста) |
| статусы mint/honey/alert | без изменений | без изменений (читаются на тёмном) |

Реализация: CSS-переменные shadcn-конвенции (`--background`, `--foreground`, `--card`,
`--primary`, ...) маппятся на токены выше; переключение — класс `dark` на `<html>` +
`nativeTheme` для нативного хрома. Все компоненты — shadcn/ui, кастомизированные этими
токенами; иконки Heroicons (outline 20px в тулбарах, mini 16px в шапках девайсов).

## Анимации

Плавные и лёгкие: только transform/opacity, 120–180ms, `ease-out`; никаких
layout-анимаций на канвасе (двигается через transform), respects `prefers-reduced-motion`.
