## Risk register

| Риск | Вероятность | Митигация |
|---|---|---|
| Пересечение по файлам | низкая при zero-overlap | сверять диффы при приёмке |
| Джиттер позиционирования WebContentsView (R1, спека §9a) | средняя до спайка | не принимать вёрстку канваса без живой проверки скролла с 10 вьюшками |
| AGPL-контаминация (заимствование из responsively-app) | низкая | при приёмке сверять новые зависимости и «слишком знакомый» код |
| Хрупкость CDP/DevTools API (R3) | средняя | изолировать в CDPController/DevToolsManager; fallback detach-режим |

## Готовность к запуску

- [ ] Все agent-промпты написаны (`W<N>-AGENT-*.md`).
- [ ] Границы файлов не пересекаются; владелец `src/shared/ipc.ts` назначен.
- [ ] У каждой задачи есть критерий готовности и требование обновить доки.
- [ ] Пункты заведены в `docs/ROADMAP.md` §10.
