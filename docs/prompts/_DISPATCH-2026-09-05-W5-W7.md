**Тип:** три последовательные волны реализации, каждая — одна длинная сессия Fable 5.1
**База:** `main` = `1cc4fe9` (merge W4) + docs-коммит этой программы
**Затронуто ядро:** да (CDPController, ViewManager, `src/shared/ipc.ts`) — в каждой волне один агент, поэтому хаб IPC агент правит сам, координатор проверяет на ревью

Механические подзадачи внутри волны (перенос данных, форматирование, массовые правки) агент делегирует субагентам **Haiku 4.5 / Sonnet 5**. Ревью — Opus 5.

## Матрица владения файлами
В каждой волне один агент владеет всем репозиторием, кроме: `docs/ROADMAP.md` (координатор; агент оставляет черновик записи в отчёте), `docs/prompts/` (координатор). Планы W6/W7 агент W5 не трогает.

## Порядок приёмки волны
1. Агент сдаёт: ветка, отчёт `docs/progress/W<N>-*.md`, вывод всех гейтов, список изменённых файлов, риски, черновик записи ROADMAP.
2. Координатор: диффа-ревью (безопасность §7a, перф §8, IPC-валидация, лицензии, UX-приоритет), прогон гейтов на своей стороне, живой запуск.
3. Вердикт: принять (merge в `main`, ROADMAP §10/§11) или вернуть с чётким списком (фикс-волна тем же агентом через SendMessage).

## Risk register

| Риск | Вероятность | Митигация |
|---|---|---|
| Длинная сессия обрывается (лимит контекста/API) | средняя | коммит после каждой задачи + рабочий лог `docs/progress/W<N>-log.md`; продолжение тем же промптом с указанием «продолжи с задачи K» |
| Нативная вьюшка выше DOM — оверлеи/направляющие невидимы | высокая (известно) | CSS-слои внутри страницы через insertCSS; интеракция направляющих — на полосе линейки; доказательство скриншотом |
| `Runtime.enable` на N вьюшках роняет перф | средняя | агрегировать, батчить, замерять p99; при регрессии — включать Runtime лениво (после первой ошибки/по запросу) |
| Каталог устройств — заимствование из Responsively | низкая | источник только Chromium DevTools (BSD-3) + открытые справочники; атрибуция в NOTICE; сверка на ревью |
| Форматы MCP-клиентов устарели к W7 | средняя | перед W7 — короткий Sonnet-ресёрч-апдейт по таблице клиентов |
| Fable-агент «улучшает» UX сверх нужного (перегруз) | средняя | UX-карта в плане: новые элементы только в Emulate-popover, ⋯-меню и kebab девайса; ревью по критерию «1 клик, нет шума» |
