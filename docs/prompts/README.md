# prompts/ — промпты для агентов и dispatch-волн

Здесь координатор (`/lead`) хранит промпты для исполнителей и планы параллельных волн.

## Файлы

| Паттерн | Назначение |
|---|---|
| `_TEMPLATE-AGENT.md` | Шаблон промпта одного агента-исполнителя |
| `_TEMPLATE-DISPATCH.md` | Шаблон dispatch-документа волны |
| `W<N>-AGENT-<буква>-<тема>.md` | Промпт конкретного агента волны N |
| `_DISPATCH-YYYY-MM-DD-W<N>.md` | План волны N (топология, владение файлами, порядок приёмки) |
| `TASK-YYYY-MM-DD-<тема>.md` | Промпт одиночной задачи (вне волны) |
| `_ARCHIVED-*.md` | Закрытые промпты (для истории) |

## Соглашения

- Волны нумеруются `W1`, `W2`, … (независимо от пунктов ROADMAP).
- Каждый agent-промпт обязан содержать границы файлов, критерий готовности, команды
  проверки и требование обновить документацию (см. шаблон).
- После завершения волны — отчёт в [`../progress/`](../progress/), запись в
  [`../ROADMAP.md`](../ROADMAP.md) §10/§11.
