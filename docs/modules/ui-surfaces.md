# Всплывающий UI и нативные превью

## Исправление 0.1.1

`z-index` не перекрывает Electron `WebContentsView`. `UiSurfaces` создаёт общий
нативный `View` для канвас-слоя и docked DevTools. Их менеджеры продолжают управлять
дочерними bounds и visibility; общий слой не меняет жизненный цикл страниц.

`NativeSurfaceGuard` наблюдает появление и удаление общих Radix-поверхностей и
подсказок адресной строки. События объединяются через rAF. При первом открытии
`ui:surface-snapshots` снимает только видимую часть каждого нативного viewport
(не весь документ), не более трёх одновременно, с таймаутом 250 мс на кадр.
Снимки выводятся под UI, затем `ui:cover-surfaces` скрывает общий нативный слой.
После удаления последней поверхности слой снова виден; снимки освобождаются.
Страницы не перезагружаются. Nested select/menu используют те же снимки.

Для интерактивных popover снимки обновляются по вводу, выбору параметров и
наведению на overflow-строку с объединением событий на 100 мс. Захват использует
`stayHidden: true`: изменения эмуляции и подсветки видны, но нативный слой не
всплывает поверх формы. Простаивающая панель не создаёт поток скриншотов.

Снимки нужны только на время всплывающего UI, не записываются на диск. Видео и
анимация превью визуально стоят на кадре до закрытия поверхности. При сбое захвата
меню остаётся доступным, но соответствующий фрагмент фона может быть пустым.
Перезагрузка или падение renderer восстанавливает нативный слой.

## Визуальные правила

- Общие scrollbar-стили относятся к оболочке; CSS проверяемых сайтов не меняется.
- Bounds канваса используют `clientWidth/clientHeight`, исключая scrollbar gutter.
- Размеры иконок: тулбар 20px, компактные действия устройств 16px, цели клика 32/24px.
- Шапка девайса 40px + 4px отступа; имя и размеры на двух строках. На узких
  превью быстрые действия скрываются, а меню сохраняет их доступными.
- Popover/Select/Dropdown ограничены свободной высотой окна; длинные диалоги
  прокручиваются внутри с отступами от краёв. Подменю и tooltip имеют свои слои.
- `cn` явно регистрирует Respo font-size классы в tailwind-merge: размеры текста
  больше не теряются при добавлении `text-foreground`.
- Автовозврат фокуса после закрытия меню не открывает tooltip повторно.

## Проверка

`e2e/ui-polish.spec.ts` проверяет реальную видимость общего нативного слоя,
наличие фоновых снимков, открытие меню/диалога при docked DevTools, возврат после
Escape, тёмную тему и границы панели в окне 720×480. Клиппинг, раскладки и dock
покрыты существующими Electron e2e. Unit-тесты защищают typography merge и gutter.

`scripts/screenshots.mjs` снимает именно окно Respo через Windows compositor
(`desktopCapturer`, выбор по `getMediaSourceId`), включая дочерние нативные поверхности.
Профиль отдельный; пользовательские данные не используются. `docs/assets/demo.html`
содержит фиктивный dashboard Northstar без внешних ресурсов.
