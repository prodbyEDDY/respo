# progress/ — отчёты о завершённых волнах и фазах

Здесь координатор фиксирует итоги крупной завершённой работы. Один файл = одна волна/фаза.

## Формат отчёта

Имя: `W<N>-<тема>-YYYY-MM-DD.md` или `PHASE-<...>-YYYY-MM-DD.md`.

```markdown
# Отчёт — W<N> <тема>

**Период:** YYYY-MM-DD … YYYY-MM-DD · **Статус:** ✅ завершено

## Что сделано
- <ключевые результаты, с коммитами>

## Затронутые файлы
- `<...>` — <что изменилось>

## Проверка
- <результаты verification-гейта>

## Документация
- какие доки обновлены; запись в ROADMAP §10/§11 сделана.

## Остаточные риски / follow-ups
- <что осталось, что отложено>
```
