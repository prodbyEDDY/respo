## Баг ядра, найденный при съёмке скриншотов для README (исправлен в W6) ✅

- **Симптом:** при зуме канваса < 100 % мобильные вьюшки (iPhone/Pixel/iPad) **не масштабировались, а обрезались**: страница рисовалась 1:1 в рамку половинного размера (десктопы — корректно). Воспроизведено на чистом `main` (6d80e87) отдельным worktree — баг существовал с W1: e2e `zoom.spec` проверял только `innerWidth`/`zoomFactor`, не картинку. `BrowserWindow.capturePage` WebContentsView не видит (белые прямоугольники), поэтому и Playwright-скриншоты ничего не показывали — увидел на OS-скриншоте.
- **Причина:** Chromium под `mobile: true` игнорирует page zoom полностью — `setZoomFactor(0.5)` не уменьшает картинку (что и записано в CLAUDE.md), а другого механизма масштабирования для mobile не было.
- **Фикс:** `metricsOf` (`cdp-controller.ts`) отдаёт `scale: zoom` для mobile (тот же параметр `Emulation.setDeviceMetricsOverride.scale`, которым DevTools вписывает телефон в маленькое окно) и `scale: 1` для desktop; `setZoom` теперь пересылает override и для mobile (раньше ранний return); `capture()` на время скриншота ставит `scale: 1` (иначе PNG уменьшился бы вместе с картинкой) и восстанавливает. **Побочный эффект, проверенный e2e:** с `scale` Chromium сам пересчитывает координаты `Input.dispatchMouseEvent` — деление на zoom для mobile в `SyncEngine.applyMouse` стало двойным масштабированием (клик уезжал на 0.2 доли), удалено: координата — CSS-px страницы при любом зуме для обоих механизмов. Inspector (`css × zoom → widget`) с `scale` стал корректным для mobile при зуме (раньше при зуме ≠ 100 % промахивался).
- **Проверено:** новый e2e `zoom.spec` «a mobile device is painted at the canvas zoom, not clipped by it» — фикстура `frame.html` (тёмная рамка по краю вьюпорта), `wc.capturePage()` iPhone при 75 %: ширина 295 и тёмные пиксели у правого/нижнего края (= вьюпорт целиком в виджете); `sync.spec` «mirrored click at 50 %» проходит без деления; `inspect`/`screenshots`/`clipping`/`emulation` — зелёные. Юниты: cdp-controller +2 (scale для mobile, unscale на capture), sync-engine переписаны под новую арифметику. CLAUDE.md — грабля обновлена.
