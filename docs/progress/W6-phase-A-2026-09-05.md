## Решения

1. Ошибки рендерера в лог — через main-событие `console-message`, без IPC-канала (CLAUDE.md §4/§6).
2. `lastCheckAt` ставится только при `up-to-date`: найденный, но не нажатый релиз вернёт чип на следующем запуске; упавшая проверка тоже повторится.
3. Тестовый фид — только loopback, через `updateConfigPath` (yml в профиле), не `setFeedURL` (тот не покрывает шаг загрузки).
4. Иконки рендерит Electron: после ревью `sharp` удалён — его бинарники libvips LGPL-3.0 нарушали §1 даже как dev-зависимость. Новых зависимостей ради иконок не осталось, кроме MIT-упаковщиков png-to-ico/png2icons.
5. `Ctrl+Alt+Delete` → `Ctrl+Alt+Backspace`: SAS Windows недостижим для приложений.
6. Скриншоты README — OS-уровень (`BrowserWindow.capturePage` WebContentsView не видит), собственная демо-страница, без сторонних сайтов.
7. README/CHANGELOG описывают **0.1.0 = main + W5 + W6** — по замыслу релиза; актуальность после мержа W5 перепроверить (устройства 110, хоткеи `Ctrl+R`/`Alt+R`, кнопка Emulate на скриншотах).

**§11 — 2026-09-05 — Иконки рендерит Electron; sharp исключён из-за LGPL-бинарников.** *Контекст:* ревью фазы A нашло 14 пакетов `@img/sharp-libvips-*` (LGPL-3.0) в lock, dev+optional. *Решение:* не вводить исключение в §1, а убрать зависимость: `scripts/icons.mjs` исполняется Electron'ом (canvas → PNG). *Причина:* публичный MIT-репозиторий с LGPL в дереве — лишний вопрос без нужды; Chromium растеризует SVG не хуже. *Последствия:* правило §1 остаётся без исключений; `npm run icons` требует установленного Electron (он и так devDependency).

**§11 — 2026-09-05 — Мобильные вьюшки масштабируются через CDP `scale`.** *Контекст:* при зуме канваса < 100 % телефоны обрезались (с W1; e2e проверял только `innerWidth`). *Решение:* `setDeviceMetricsOverride.scale = zoom` для mobile, desktop — как раньше (пре-деление); координаты `Input.dispatchMouseEvent` — CSS-px страницы при любом зуме, деление в SyncEngine убрано. *Последствия:* новый пиксельный e2e; грабля в CLAUDE.md переписана; `BrowserWindow.capturePage` не видит WebContentsView — окно снимать OS-уровнем.

**§11 — 2026-09-05 — «Очистить всё» = `Ctrl+Alt+Backspace`.** *Контекст:* `Ctrl+Alt+Delete` (W4) перехватывается Windows (SAS). *Решение:* Backspace; README/CHANGELOG/меню обновлены.
