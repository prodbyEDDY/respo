## Task 1 — Emulation pack ✅

- **Сделано:** `shared/emulation.ts` (нouns: профиль, пресеты сети как в DevTools, 8 городов, 11 локалей, 11 таймзон, гарды/парсеры), `main/emulation.ts` (EmulationManager: глобальный профиль + пер-девайс override vision, регистрация вьюшек по образцу Inspector, restore из persistence **до** первой вьюшки), `CDPController.applyEmulation` (диффит по группам — одна CDP-команда на изменённую группу; replay после реаттача; `Accept-Language` едет в том же `Network.setUserAgentOverride`, что и UA — второй вызов перетёр бы первый), IPC `emulation:set` / `emulation:set-device-vision` / `emulation:get` с валидацией, слайс `emulation` в документе (field-level repair, `SCHEMA_VERSION` не бампал — «отсутствует = дефолты», как у `layout`/`devtools`; бамп сбросил бы документ пользователя в бэкап ради опционального поля), стор `stores/emulation.ts`, кнопка **Emulate** с точкой-бейджем слева от SYNC + popover (`EmulatePopover.tsx`), shadcn `ui/select.tsx`, общий `common/Segmented.tsx` (SettingsDialog переведён на него).
- **Проверено фактически (Chromium 152.0.7977.54):** все 7 типов `setEmulatedVisionDeficiency` поддерживаются; `Network.emulateNetworkConditions` работает **без** `Network.enable` (offline валит загрузку всех 5 вьюшек); все overrides живут в CDP-сессии и **переживают навигацию/reload без реаппликации** (только реаттач требует replay — сделан); мусорный timezone Chromium отвергает («Invalid timezone id» → лог, остальное применяется), мусорную locale — молча принимает (поэтому валидация BCP 47 на нашей стороне обязательна). Offline не действует на `file://` (загрузчик файлов минует network service) — e2e поднимает локальный http-сервер.
- **UX-решения:** выбор города в Location также ставит таймзону (строка Time zone показывает результат); Off у Location чистит только координаты; при активной локации — подсказка «Sites still have to ask for permission» (разрешение остаётся «спрашивать»). Reset all — одна кнопка в шапке popover, disabled когда нечего сбрасывать.
- **Отложено:** произвольная локаль/таймзона текстом (только пресеты); e2e на geolocation (нужен allow разрешения — вручную проверено `setGeolocationOverride` принимается, юниты покрывают параметры); vision e2e — в Task 5.
- **Цифры:** юниты 947 (shared+main) + 393 (renderer) — все зелёные; новых: `shared/__tests__/emulation.test.ts`, `main/__tests__/emulation.test.ts`, `stores/__tests__/emulation.test.ts`, +11 в cdp-controller, +8 в validate, +8 в persistence-types. e2e `emulation-pack.spec.ts` 1/1 (dark/light, reduced motion, print, de-DE → `navigator.language`+`Intl`+`Accept-Language` на всех 5 запросах, Asia/Tokyo, reload, offline → 5 failed, reset, рестарт → первый же запрос уже fr-FR и dark).
