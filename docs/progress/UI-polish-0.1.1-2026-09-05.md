# Respo 0.1.1 — UI polish и публикация

Выпущен 2026-09-05. [PR #1](https://github.com/prodbyEDDY/respo/pull/1)
слит в `main`, коммит `8c654490e645a5965d674ced92470934f0ac0ecf`, тег `v0.1.1`.

## Результат

- Меню, select, подсказки и диалоги отображаются над нативными превью и DevTools.
  Общий слой временно уступает место снимкам; ввод в интерактивной панели обновляет
  снимок, закрытие возвращает живые страницы. Есть резервный захват через Chromium.
- Исправлена гонка первого layout: измерения, пришедшие до создания устройств,
  сохраняются и применяются после их создания. Загруженные окна не остаются 0×0.
- Исправлены потеря typography-токенов в class merge и перекрытие scrollbar gutter.
  Скроллбары оболочки, размеры иконок, компактные шапки, focus и границы панелей
  приведены к общим правилам; проверено окно 720×480.
- Выбрана монограмма R, пересобраны SVG/PNG/ICO/ICNS и иконки установщика.
  Обновлены README, описание репозитория и четыре реальных Windows-скриншота.
  Сохранены demo и воспроизводимые генераторы; логи исключены из приложения.
- Релизный workflow загружает EXE, blockmap и latest.yml в один draft и только
  после этого публикует его. Impeccable удалён из обеих глобальных папок по просьбе владельца.

## Проверка

- Typecheck и lint: успешно.
- 1 595 unit-тестов в 72 файлах; два новых теста защищают ранний layout.
- Все 40 Electron E2E прошли в [CI PR](https://github.com/prodbyEDDY/respo/actions/runs/33967508159)
  и [CI main](https://github.com/prodbyEDDY/respo/actions/runs/33967869648).
- Windows packaging в CI: успешно. Локальный NSIS и упакованный Respo.exe проверены
  на отдельном профиле: запуск, видимые bounds, меню, обычный/резервный захват,
  восстановление нативного слоя. Пользовательская установка не перезаписывалась.
- [Релизная сборка](https://github.com/prodbyEDDY/respo/actions/runs/33967911890): успешно.
  Публичная ссылка на EXE отвечает HTTP 200; размер 117 326 250 байт.
  GitHub latest указывает на v0.1.1; все три файла опубликованы.
