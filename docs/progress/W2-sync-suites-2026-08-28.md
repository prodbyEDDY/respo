## Что сделано

- **SyncEngine** (сердце продукта): sandboxed-preload вьюшек (ничего не экспонирует страницам — проверено по скомпилированному артефакту; `isTrusted`-гейт против форджа), rAF-коалесинг, применение через CDP Input + скролл по доле; lead-election по hit-test (mouseenter над нативной вьюшкой не работает); пер-девайс/глобальный тумблеры; follower-silencing (10 IPC/кадр → 1). Перф: p99 main 2.4 мс при 10 девайсах. Зеркалирование клика при зуме — CDP-координаты zoom-relative, деление на zoom + e2e-доказательство.
- **Персистентность**: electron-store за типизированным IPC, debounce, schemaVersion, гидрация сторов; тема/сьюты/мьюты/поворот переживают рестарт.

- **Follow-ups W1**: e2e-гард клиппинга, честные back/forward, rotate на девайсе, Inter (@fontsource), индикация невалидного URL.
